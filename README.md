# SiteModel

SiteModel is a web-based BIM/CAD project workspace for importing construction model files, viewing 3D models in the browser, and managing project model context.

## Current MVP

- Project navigation shell
- BIM/CAD import panel
- Browser-loaded GLB/GLTF model preview
- Three.js sample coordination viewer
- Object list with selection state
- Properties inspector with editable object name, color, and progress
- Version strip for model file context

## Tech Stack

- React
- TypeScript
- Vite
- Three.js
- @react-three/fiber
- @react-three/drei
- Lucide React
